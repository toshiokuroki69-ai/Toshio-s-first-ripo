# Grammar Quest

英文法を学びながら進めるドット絵RPG風の学習アプリです（iPhone向けWebアプリ / PWA）。App Store や Mac は不要で、Safari から「ホーム画面に追加」するとアプリのように使えます。

## 遊び方

- マップのエリアを順に攻略します。エリアごとに文法テーマがあり、ボスをたおすと次のエリアが開きます。
- 戦闘では問題に正解すると敵にダメージ、まちがえると自分がダメージを受けます。
- 「ちしきの書」でそのエリアの文法を確認できます。
- まちがえると、あなたの答え・正解・解説が表示され、「もう一度ちょうせん」でその場で解き直せます（ダメージなし・成功で半分のダメージ）。
- 戦闘のあとに「ふりかえり」でまちがえた問題を一覧でき、その問題だけに再挑戦できます。
- まちがえた問題は町の「修行場」に集まり、まとめて復習できます。
- やくそう（HP回復）と見やぶりのメガネ（ヒント）をどうぐ屋で買えます。
- 7体のボスをすべてたおすと、裏ボスの「魔王城」（英作文）が現れます。

| エリア | 文法 | 問題形式 |
|---|---|---|
| 見習いの村（任意） | 中学基礎：冠詞・前置詞・時制の基本 | 4択・並べ替え |
| 時の森 | 現在完了・過去完了 | 4択・並べ替え |
| 助動詞の洞窟 | 助動詞・助動詞 + have 過去分詞 | 4択・並べ替え |
| 受け身の沼 | 受動態 | 4択・並べ替え |
| 準動詞の砦 | 不定詞・動名詞・分詞 | 4択・並べ替え |
| 関係詞の迷宮 | 関係代名詞・関係副詞・what | 4択・並べ替え |
| 比較の塔 | 比較 | 4択・並べ替え |
| 仮定法の城 | 仮定法 | 4択・並べ替え |
| 魔王城（裏） | 全範囲の英作文 | 英作文 |

見習いの村は「せってい」で表示／非表示を切り替えられます。

## 保存について

冒険の記録は端末のブラウザに保存されます。iPhone の Safari はしばらく使わないとデータを消すことがあるため、町の「ふっかつのじゅもん」をメモアプリなどに控えておくと安心です。じゅもんは別の端末への引き継ぎにも使えます。

## iPhone で使う手順（GitHub Pages）

1. GitHub でこのリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを選んでフォルダは `/ (root)` にして保存
3. 数分後に表示される URL を iPhone の Safari で開く
4. 共有ボタン →「ホーム画面に追加」

## 問題を追加するには

`js/data.js` の各エリアの `qs` に追加します。

```js
// 4択：___ が空欄、a は正解の番号（0始まり）
{ t: "mc", q: "I ___ to London three times.", c: ["have been", "went", "have gone", "am going"], a: 0, e: "解説" }
// 並べ替え：w が正しい順、x はダミーの語、alt は別の正解順
{ t: "order", ja: "私は一度も雪を見たことがない。", w: ["I", "have", "never", "seen", "snow"], x: ["saw"], e: "解説" }
// 英作文：need の各グループから1つずつ含まれていれば正解
{ t: "write", ja: "この橋は100年前に建てられた。", hint: "受動態", ans: ["This bridge was built 100 years ago."],
  need: [["this bridge was built"], ["100 years ago", "a hundred years ago"]], e: "解説" }
```

## ファイル構成

- `index.html` … 入り口
- `css/game.css` … 見た目
- `js/data.js` … エリア・敵・解説・問題データ
- `js/sprites.js` … ドット絵（16×16）
- `js/game.js` … ゲーム本体
- `manifest.webmanifest` / `sw.js` / `icons/` … ホーム画面アイコンとオフライン対応
